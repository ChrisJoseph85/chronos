# Questions for the user

The Manager appends here when something needs a human decision. **It does not
wait for an answer** — it takes the recommended default, marks the work
provisional, and continues (see `docs/manager.md` §8).

When the user answers, the Manager revisits the provisional work and adjusts.

Format: **date — question — options — recommended default — what was done meanwhile
— current status.**
